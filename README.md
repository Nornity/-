# НИЖНИЙ УРОВЕНЬ

Хоррор-игра от первого лица на чистом HTML/CSS/JS (один файл, без библиотек).
Рейкаст-рендер в стиле Wolfenstein 3D, процедурные текстуры, спрайты и звук.

## Запуск

Откройте `index.html` в браузере, либо:

```bash
python3 -m http.server 8080 --bind 0.0.0.0
# http://localhost:8080
```

Быстрый просмотр финальной катсцены: в меню включить «Я РАЗРАБОТЧИК», начать уровень
и нажать **N** — игрок ставится к шлюзу и сразу играется открытие + спуск по лестнице.

## Управление (десктоп)

`WASD` — движение · `Shift` — бег · `C` — присед · `F` — фонарь ·
`Space` — шокер · `R` — перезарядка · `Q` — камень · `E` — действие · `M` — карта

## Игра на Андроиде (сенсорный экран)

На смартфоне автоматически включается тач-режим:

- левый виртуальный стик — движение (вперёд/назад/стрейф);
- свайп по экрану — поворот камеры (та же сглаженность, что у мыши);
- кнопки справа: **ШОКЕР** (большая), **R** — перезарядка, **Q** — камень,
  **E** — действие у шлюза/стен;
- кнопки слева: **БЕГ** (удерживать), **ПРИСЕД** (переключатель);
- справа сверху: пауза, карта, фонарь.

Запуск на телефоне: откройте `index.html` в Chrome (или включите GitHub Pages —
тогда игра будет доступна по ссылке). Десктопное управление на тач-устройствах
не мешает: клавиатура и мышь продолжают работать, если подключены.

## Победа на уровне

Соберите все предохранители и доберитесь до аварийного шлюза. После `E` у шлюза:

1. камера доворачивается к двери, лязг разблокировки, створки разъезжаются (1.6 с,
   пауза разблокировки + вибрация механизма + свет и искры из проёма, прогресс-бар);
2. игрок подходит, свет затапливает кадр, затемнение — вход в шлюз, лязг закрывшейся двери;
3. **спуск по лестнице от первого лица** (~7 с): лестничный марш идёт горизонтально
   через кадр, ступени с жёлтыми носиками, перила, мигающая аварийная лампа,
   качание камеры и шаги на каждой ступени, глухие удары монстра в закрытый шлюз за спиной;
4. свет внизу, переход на экран победы (в бесконечном режиме — на следующий этаж).
